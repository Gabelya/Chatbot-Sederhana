Chatbot ini dibuat menggunakan Python dengan modul datetime, difflib, dan random.
Fungsinya adalah menjawab pertanyaan sederhana seperti waktu, tanggal, serta memberikan hiburan berupa lelucon, tebak-tebakan, dan fakta unik
=====Fitur Utama=====
Salam & interaksi dasar: menjawab "halo", "hai", "apa kabar", "terima kasih".
Informasi waktu:
1. Hari apa
2. Jam berapa
3. Tanggal berapa
4. Bulan apa
5. Tahun berapa
Hiburan:
1. Lelucon acak 😂
2. Tebak-tebakan acak 🤔
3. Fakta unik 🐾

====Struktur Kode=====
responses: dictionary untuk jawaban standar.

jokes: list berisi kumpulan lelucon.

riddles: list berisi kumpulan tebak-tebakan.

facts: list berisi kumpulan fakta unik.

chatbot(): fungsi utama yang menjalankan loop interaktif.


======Cara Menjalankan========
1. Pastikan Python 3 sudah terinstall.
2. Clone repository:
git clone https://github.com/Gabelya/Chatbot-Sederhana.git
cd Chatbot-Sederhana

3. Jalankan program:
   python chatbot.py

======Contoh Interaksi=======
Selamat datang 😊
Apa yang bisa saya bantu? 😊
Anda: halo
Chatbot: Halo juga! 😊

Anda: hari apa
Chatbot: Hari ini Saturday, 02 May 2026 🗓️

Anda: buat lelucon
Chatbot: Kenapa programmer bingung di supermarket? Karena mereka tidak bisa menemukan 'array'! 😂
